# Campo Beto: descargas

Acá está la app **Campo Beto** para Android, lista para instalar.

**Para instalar:** abrí la última versión en *Releases*, tocá `CampoBeto.apk`, y cuando termine de bajar, tocá *Abrir*. Si el teléfono pregunta, permití "instalar apps de origen desconocido" para el navegador.

Este repositorio tiene sólo el archivo para instalar; el código de la app no está acá.
